# 简历句子：说明项目能力，不补个人功劳

来源：[S3 · 简历素材](sources.md#s3--简历素材)。这句话根据本项目已实现功能整理，不是外部候选人的简历。

**输入原文：**

> 使用 Python 实现竞品周报，支持离线演示、版本与评分对比，以及模型调用失败时保留更新说明原文。

## 老板版

已实现竞品周报，能在不联网时演示，比较版本与评分，并在模型调用失败时保留更新说明原文。原文未提供节省时间或成本的数据。

## HR / 外行版

做了一个比较同类应用变化的周报工具，像把前后两份记录摆在一起看：它能比较版本和评分，也能在不联网时演示。自动整理说明的服务失败时，仍保留更新说明原文供查看。

## 研发版

使用 Python 实现竞品周报，支持离线演示、版本与评分对比，以及模型调用失败时保留更新说明原文。缺少对比数据来源、离线演示覆盖范围和调用失败的判定口径；原文也未说明个人职责，不能改写成“独立实现”或“主导开发”。

## 核对

- 输入没有数字，三版未增加用户量、准确率、节省工时或覆盖规模。
- HR 版以“不联网时演示”解释离线，以“自动整理说明的服务”解释模型调用，保留实际能力。
- 研发版保留 Python；HR 版省去实现语言，未改变功能事实。
- 三版未虚构个人职责、团队规模或业务收益。
