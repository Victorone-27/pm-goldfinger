# 技术方案：先查保险条款，再组织回答

来源：[S5 · 用户提供的技术方案示例](sources.md#s5--用户提供的技术方案示例)。

**输入原文：**

> 用 RAG 加向量检索回答保险条款问题

## 老板版

方案是先从保险条款里找出与问题相关的内容，再让模型据此组织回答。

## HR / 外行版

像先翻保险条款再答疑：先找出意思上和问题接近的条款内容，再让人工智能根据这些内容组织回答。

## 研发版

采用 RAG：通过向量检索召回与保险条款问题相关的内容，再交给生成模型据此组织回答。缺少条款来源与版本、切分方式、检索阈值、回答评估口径，以及未检索到相关内容时的处理规则。

## 核对

- 原文无数字，三版没有增加准确率、响应时间或成本指标。
- “按意思找相关内容，再据此生成回答”解释 RAG 与向量检索的工作方式，没有增加具体模型、数据库或技术参数。
- 保持方案身份，没有声称已上线、答案一定正确、一定附引用或一定节省人力。
