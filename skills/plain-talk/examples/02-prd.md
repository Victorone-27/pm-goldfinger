# PRD 片段：按条件导出订单

来源：[S2 · 按用户要求编写的示例需求](sources.md#s2--按用户要求编写的示例需求)。这是 Codex 编写的常见 PRD 演示片段，属于待实现需求。

**输入原文：**

> 在订单列表页新增批量导出功能，支持按订单状态和下单时间筛选，单次最多导出 1000 条订单，导出内容为订单号、下单时间、订单状态。无符合条件的数据时，展示空状态提示，不生成文件。

## 老板版

这次需求要让用户按条件拿到一份订单清单。在订单列表页按订单状态和下单时间筛选后导出，每次最多 1000 条，包含订单号、下单时间和订单状态。没有符合条件的订单时，给出提示，不生成文件。

## HR / 外行版

要让用户像从一沓单据里挑出需要的那些一样，在订单列表里按订单状态和下单时间选出订单，保存成文件；每次最多 1000 条，文件里列出订单号、下单时间和订单状态。没有符合条件的订单时，要给出提示，不生成文件。

## 研发版

在订单列表页新增批量导出功能：按订单状态和下单时间筛选，单次最多导出 1000 条订单，字段为订单号、下单时间、订单状态；结果为空时展示提示且不生成文件。缺少可选订单状态、时间边界与时区、文件格式、超出数量上限时的处理规则，以及导出权限和失败处理的验收口径。

## 核对

- `1000` 在三版均表示单次导出的订单数量上限，“最多”保留，未改成每次必须导出 1000 条。
- 页面、两个筛选条件、三个导出字段和空结果行为均保留；没有增加导出格式或自动重试等需求。
- 三版均保持“要新增”的需求身份，没有改写成已经上线的功能；本例无数字换算。
