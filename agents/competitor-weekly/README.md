# 竞品周报

每周对比竞品的 App Store 更新，生成只报告变化的中文周报，后续增加小红书口碑变化。

状态：开发中。M0 仅建立目录，M1 实现 App Store 周报，M3 增加口碑模块。

| 目录 | 用途 |
| --- | --- |
| `src/` | 抓取、快照、比较、解读与报告逻辑 |
| `prompts/` | 模型提示词 |
| `fixtures/` | 明确标注为测试数据的离线样本 |
| `schedule/` | macOS launchd 安装与卸载脚本 |
| `tests/` | 周报行为测试 |
| `data/` | 本地运行数据，不提交到 Git |
| `reports/` | 真实周报不提交；可公开示例放在 `examples/` 子目录 |

配置、运行入口、周报示例和定时任务安装说明将在 M1 提供。
